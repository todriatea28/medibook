# MediBook — ციფრული სამედიცინო ჰაბი და პაციენტების მართვის პლატფორმა

**Live Demo:** [აქვე შეგიძლია ჩასვა შენი Vercel-ის ლინკი]  
**კატეგორია:** სამედიცინო ჰაბი / პაციენტების მართვის სისტემა  

---

## პროექტის შესახებ
**MediBook** არის React-ზე დაფუძნებული თანამედროვე ვებ-აპლიკაცია, რომელიც უზრუნველყოფს პაციენტებისა და ექიმების ეფექტურ ურთიერთქმედებას. სისტემა საშუალებას აძლევს მომხმარებლებს მოძებნონ ექიმები სპეციალობის მიხედვით, დაჯავშნონ ვიზიტები, აკონტროლონ სტატუსები, მიიღონ დიაგნოზები და შეაფასონ ვიზიტები[cite: 7].

## ძირითადი ფუნქციონალი
- **მონაცემთა მართვა (CRUD & State):** გლობალური სთეით-მენეჯმენტი Zustand-ის გამოყენებით (`persist` middleware), რომელიც უზრუნველყოფს მონაცემების სინქრონიზაციას `localStorage`-თან[cite: 8].
- **ძიება და ფილტრაცია:** ოპტიმიზებული ცოცხალი ძიება და მემოიზებული ფილტრაცია `useMemo`-ს გამოყენებით[cite: 8].
- **მოდალური ფანჯრები და ვალიდაცია:** `ReactDOM.createPortal` მოდალები და მკაცრი ფორმის ვალიდაცია `Zod`-ით[cite: 8].
- **მდგრადობა (Resilience):** `ErrorBoundary` დაცვა თეთრი ეკრანისგან, Double-Click ბლოკირება და ოფლაინ/დემო მონაცემების Fallback რეჟიმი[cite: 8].
- **Responsive დიზაინი:** Mobile-First მიდგომა, სრულად ადაპტირებული ბადეები მობილურიდან (375px) დესკტოპამდე (1440px)[cite: 8].

## ტექნოლოგიური სტეკი

| კატეგორია | გამოყენებული ტექნოლოგია |
|---|---|
| **Core** | React, Vite, JavaScript / TypeScript |
| **State Management** | Zustand (Persist Middleware) + LocalStorage[cite: 9] |
